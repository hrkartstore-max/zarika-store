# Zarika Store

A responsive e-commerce storefront built with Next.js 15, React 19, and TypeScript.

## Features
- Product listing and product detail pages
- Category browsing and search
- Cart drawer and cart page
- Checkout and order confirmation screens
- Wishlist, account, blog, and order tracking pages
- Responsive styling and local product imagery

## Requirements
- Node.js 20 or later
- npm

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```

## Deployment
This project can be deployed to Vercel after the complete source and public assets are pushed. Configure any required environment variables in the deployment dashboard; never commit secrets.
